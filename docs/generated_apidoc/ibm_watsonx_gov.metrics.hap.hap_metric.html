Hap Metric¶

pydantic model ibm_watsonx_gov.metrics.hap.hap_metric.HAPMetric¶

Bases: GenAIMetric

Defines the HAP metric class.

The HAP metric measures if there is any toxic content that contains hate, abuse, or profanity in the input. It is computed using the hap model.

Examples

  1. Create HAP metric with default parameters and compute using metrics evaluator.
    metric = HAPMetric()
result = MetricsEvaluator().evaluate(data={"input_text": "...", metrics=[metric])
  2. Create HAP metric with a custom threshold.
    threshold  = MetricThreshold(type="lower_limit", value=0.5)
metric = HAPMetric(threshold=threshold)
